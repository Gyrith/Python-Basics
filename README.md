# 🐍 Python Basics

A beginner-friendly Python repository covering the fundamental concepts of Python programming through hands-on practice, examples, and challenges.

## 📚 About

This repository contains my Python learning journey. Each folder focuses on a specific topic and includes:

- Notes
- Practice examples
- Exercises
- Challenges
- Jupyter Notebook (`practice.ipynb`)

The goal of this repository is to build a strong Python foundation before moving into Data Science.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Python-Basics.git
```

2. Navigate to the project folder:

```bash
cd Python-Basics
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any `practice.ipynb` notebook and run the cells.
